## Download

| File | For |
|---|---|
| **beetrack-setup-….exe** | Windows 10/11: the normal choice. Installs beetrack with Start-menu and desktop shortcuts; no admin rights needed. |
| **beetrack-portable-…-windows.zip** | Windows PCs where you can't install software: unzip and double-click `beetrack.exe`. |

Nothing else to install: Python, the libraries and ffmpeg are included.

## First start

1. Double-click **beetrack**. Windows may say *"Windows protected your PC"* because the app isn't signed yet:
   click **More info → Run anyway** (once).
2. A small window opens (keep it open while you work; close it to stop beetrack) and your browser opens the app.
3. Your experiments are saved in **Documents\beetrack**. Updating or uninstalling beetrack never deletes them.

Upgrading: just run the new installer.

See the [README](https://github.com/yair-hamo/beetrack#readme) for how to use it.
